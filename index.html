How to Edit Your Stores

Each store loads all content from a single JSON file. No coding required — just edit text and numbers, save, and refresh your browser.

  1. Open any store folder (e.g. site1-verdant-haven/products.json)
  2. Edit product names, descriptions, price, originalPrice, or cost fields
  3. Change store name, colors in theme, hero text, and about section
  4. Replace product images by updating the image URL
  5. Run python3 server.py in the dropship-stores folder, then visit http://localhost:8080

The cost field is your supplier price (hidden from customers) — use it to track your profit margin.

🔒 Private admin dashboard: http://localhost:8080/admin/ — password in admin/config.json (default: dropship2026). Not linked from public stores.
